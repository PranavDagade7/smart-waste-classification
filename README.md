# ♻️ Smart Waste Classification Using Computer Vision

AI-powered Waste Classification System designed to identify and classify waste images into Organic and Recyclable categories using Computer Vision and Deep Learning. The system helps users identify waste correctly and encourages efficient waste segregation for a cleaner and greener environment.

---

## 📌 Project Overview

This project uses Artificial Intelligence and Computer Vision to analyze waste images and predict whether the waste is organic or recyclable. Using a trained deep learning model, the system classifies uploaded images and displays the predicted category with a confidence score.

Key goals:

✅ Automatically classify waste images  
✅ Identify organic and recyclable waste  
✅ Support proper waste segregation  
✅ Promote recycling and environmental sustainability  

---

## 🧠 Features

- AI-based waste image classification
- Organic and recyclable waste detection
- Deep learning using MobileNetV2
- Image upload and prediction
- Confidence score for predictions

## ⚙️ How It Works

1. The user uploads an image of waste.
2. The image is resized and preprocessed.
3. The trained MobileNetV2 model analyzes the image.
4. The system predicts whether the waste is Organic or Recyclable.
5. The predicted category and confidence score are displayed.
